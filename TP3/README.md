# TP3 — Automatisation de tests fonctionnels Selenium

## Objectif
Automatiser les parcours utilisateur du site Sauce Demo avec Selenium Python et le pattern POM.

## Site testé
https://www.saucedemo.com/

## Installation
pip install -r requirements.txt

## Exécution
# Script direct
python main.py
